Workspaces rail · icons as identity

Variant 1 from before, with the initials tile replaced by an icon you pick from a large library. The same icon then follows you everywhere you type, so you always know which workspace a message or command is going to.

  • Icon + colour are set per workspace from the row's ··· menu ("Change icon…"). Library is searchable with categories, a few hundred glyphs.
  • Row subtitle shows only the current branch.
  • On switching workspace, a small pill drops in at the top of the app for about a second with the icon and name, then slides away. The CODARA intro in new terminals goes away.
  • Folder ··· menu keeps Add workspace here, Rename folder, Delete folder. No folder counts. Working/total census unchanged.
